# Intermediate

Hands-on labs for learners who've completed Foundations (or already have basic LLM/API familiarity). Covers chunking strategies, retrieval quality, tool use, and building your first agent, ending in a multi-tool agent capstone.

All nine chapters are live: 1 (chunking strategies), 2 (choosing an embedding model), 3 (better retrieval), 4 (prompt patterns), 5 (tool use), 6 (your first agent), 7 (memory), 8 (evaluating what you built), and 9 (capstone — multi-tool agent). See the [Intermediate overview](https://fewshot-works.github.io/zero-to-agent/docs/intermediate/) on the site for details.
