# Intermediate

Hands-on labs for learners who've completed Foundations (or already have basic LLM/API familiarity). Covers chunking strategies, retrieval quality, tool use, and building your first agent, ending in a multi-tool agent capstone.

Chapters 1 (chunking strategies) and 2 (choosing an embedding model) are live. The rest are being written one at a time. See the [Intermediate overview](https://fewshot-works.github.io/zero-to-agent/docs/intermediate/) on the site for the planned chapter list.
