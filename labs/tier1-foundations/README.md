# Tier 1 — Foundations

Hands-on labs for the zero-prior-knowledge tier. Each numbered folder will correspond to one chapter in the [site](../../site) (Chapter 0 setup guide through the Tier 1 capstone).

Labs are not yet written — see `PRD.md` §7 for the planned chapter list and §15 for next steps.

Every lab in this tier will run with **either**:
- A local [Ollama](https://ollama.com) model (free, no API key), or
- Your own OpenAI or Anthropic API key (via a `.env` file, never committed)

and will use a local, file-based [ChromaDB](https://www.trychroma.com/) instance for any vector storage — no servers, no accounts.
