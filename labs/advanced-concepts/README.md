# Advanced Concepts

Hands-on labs for standalone, self-contained topics that don't belong to the Foundations/Intermediate/Advanced sequence, each one readable on its own.

Currently covers: prompt engineering (`01-prompt-engineering`), token & cost management (`02-token-cost-management`), agent security (`03-agent-security`), human-in-the-loop approval gates (`04-human-in-the-loop`), role-based access control (`05-rbac`), chaos engineering / fault injection (`06-chaos-engineering`), continuous adversarial evaluation (`07-continuous-adversarial-evaluation`), and AI gateways / multi-provider failover (`08-ai-gateways`).
